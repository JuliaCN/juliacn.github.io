安装 Julia

官方推荐使用 juliaup 安装和管理 Julia 版本。设置 JULIAUP_SERVER 后，Julia 将从国内镜像下载：

macOS / Linux

export JULIAUP_SERVER=https://mirrors.tuna.tsinghua.edu.cn/julia-releases/
curl -fsSL https://install.julialang.org | sh

Windows（PowerShell，第一行对当前窗口生效，第二行永久保存）

$env:JULIAUP_SERVER = "https://mirrors.tuna.tsinghua.edu.cn/julia-releases/"
[Environment]::SetEnvironmentVariable("JULIAUP_SERVER", $env:JULIAUP_SERVER, "User")
winget install --name Julia --id 9NJNWW8PVKMN -e -s msstore

包管理器镜像

设置 JULIA_PKG_SERVER 环境变量即可让 Pkg 从国内镜像下载注册表和包：

macOS / Linux

export JULIA_PKG_SERVER=https://mirrors.pku.edu.cn/julia

Windows（PowerShell）

$env:JULIA_PKG_SERVER = "https://mirrors.pku.edu.cn/julia"
[Environment]::SetEnvironmentVariable("JULIA_PKG_SERVER", $env:JULIA_PKG_SERVER, "User")

在 macOS / Linux 上，请把上面的 export 两行（JULIAUP_SERVER 和 JULIA_PKG_SERVER）写入 shell 配置文件（如 ~/.bashrc、~/.zshrc），否则新开的终端不会使用镜像。也可以在 ~/.julia/config/startup.jl 中写入 ENV["JULIA_PKG_SERVER"] = "https://mirrors.pku.edu.cn/julia"。

包服务器镜像（JULIA_PKG_SERVER）：

  • 北京大学 PKU：https://mirrors.pku.edu.cn/julia
  • 南京大学 NJU：https://mirror.nju.edu.cn/julia

  • 清华大学 TUNA：https://mirrors.tuna.tsinghua.edu.cn/julia-releases/
  • 北京外国语大学 BFSU：https://mirrors.bfsu.edu.cn/julia-releases/
  • 上海交通大学 SJTUG：https://mirrors.sjtug.sjtu.edu.cn/julia-releases/
  • 南京大学 NJU：https://mirror.nju.edu.cn/julia-releases/
